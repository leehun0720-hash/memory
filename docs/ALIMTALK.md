# 카카오 알림톡 연결

현재 연동은 NAVER Cloud SENS의 카카오 알림톡 API를 사용합니다. 카카오 채널과 SENS 서비스, 카카오 검수가 완료된 템플릿이 필요합니다. 실제 수신 성공 검증은 운영 계정 연결 후 진행해야 합니다.

프로젝트 `.env`에 아래 값을 설정하고 서버를 재시작합니다. 비밀키는 Git에 올리지 않습니다.

```dotenv
KAKAO_SEND_ENABLED=0
NCP_ACCESS_KEY=
NCP_SECRET_KEY=
KAKAO_SERVICE_ID=
KAKAO_CHANNEL_ID=
KAKAO_TEMPLATE_CODE=
KAKAO_TEMPLATE_CONTENT="가족 일정 안내\n일정: #{title}\n일시: #{date} (한국 시간)\n#{days}일 전 알림입니다."
```

위 문구는 검수 신청용 예시입니다. `KAKAO_TEMPLATE_CONTENT`에는 실제 승인된 템플릿 전문을 줄바꿈까지 동일하게 입력합니다. 지원 변수는 `#{title}`, `#{date}`, `#{days}`이며 버튼 없는 기본 텍스트 템플릿을 사용합니다. 채널 ID는 공급자에 등록한 `@채널아이디`입니다. 자동 SMS 대체 발송은 사용하지 않습니다.

1. 관리자 → 오늘 할 일·알림톡에서 누락된 설정을 확인합니다.
2. 가족 → 설정 → 알림·카카오 알림톡에서 휴대폰 번호와 수신 동의를 저장합니다. 동의는 가족 본인이 선택합니다.
3. 승인된 템플릿 설정을 확인한 뒤 `KAKAO_SEND_ENABLED=1`로 변경하고 서버를 재시작합니다. 활성화하면 동의한 가족의 당일 대기 알림이 실제로 발송될 수 있습니다.
4. 서버는 60초마다 일정을 확인합니다. 한국 시간 09:00~19:59에 당일 생성된 대기 건을 처리합니다. 서버가 계속 실행되어야 합니다. 서버리스의 일시적 인스턴스는 예약 발송 운영에 적합하지 않으며 상시 실행 서버를 사용합니다. SQLite 파일을 공유하는 단일 앱 프로세스로 운영합니다.
5. `접수됨`은 공급자가 요청을 받은 상태입니다. 조회 API의 `messageStatusCode=0000`을 확인한 뒤에만 `수신 성공`으로 표시합니다.
6. 확실한 실패만 당일 관리자 화면에서 수동 재요청할 수 있습니다. 통신 중단·서버 재시작으로 결과가 불명확하면 자동 재발송하지 않습니다. SENS 콘솔 발송 이력을 대조하세요. 날짜가 지난 대기 건은 만료 처리합니다.

앱 안 알림은 기본 활성화이며 카카오 알림톡은 기본 비활성화입니다. 7일 전·전날·당일, 일정 종류, 쉬는 기간을 가족별로 설정합니다. 초대가 만료되거나 철회된 가족, 불참한 약속, 취소된 일정에는 대기 중인 알림톡을 보내지 않습니다. 기일의 당일 알림도 09시 이후에 발송되므로 이른 오전 일정에는 전날 알림을 함께 켜 주세요.

운영 확인: 본인 테스트 계정과 미래 일정으로 접수→수신 성공을 확인하고, 동의 해제·일정 취소·초대 해제 후 발송이 중단되는지 확인합니다. 이 개발 작업에서는 실제 카카오 발송을 실행하지 않았습니다.

공식 문서: [발송 API](https://api.ncloud-docs.com/docs/sens-alimtalk-send), [결과 조회 API](https://api.ncloud-docs.com/docs/sens-alimtalk-get).

# 가족 기능 안내

- 추모 → 가족 앨범: 사진·영상·음성·이야기를 등록합니다. 사진은 JPEG로 보관하며 위치 정보를 제거합니다. 가족 공개는 계약자 승인 후 적용하고, AI 활용 동의는 별도입니다. 제한 공개는 작성자와 계약자만 열람합니다.
- 제사 → 기일·가족 약속: 양력·음력 반복 일정, 윤달이 없는 해와 날짜가 없는 해의 처리 방법, 참석 여부, 공동 참배 접속 표시를 제공합니다. 음력 변환은 korean-lunar-calendar 지원 범위인 2050년까지입니다. 캘린더 내보내기는 향후 2년의 개별 날짜이며 자동 구독이 아닙니다.
- 함께 참배 공간: 가족의 접속 상태를 확인하고 기존의 봉안함 카메라·마음 남기기를 이용합니다. 가족 간 영상 통화 기능은 포함하지 않습니다.
- 쉬운 화면: 큰 글씨, 단순한 글꼴, 무늬·움직임 최소화, 세 가지 시작 버튼을 제공합니다. 해당 기기에 저장됩니다.
- 추억책: PDF에 가족 앨범 사진·이야기와 방명록이 포함됩니다. 한글 글꼴은 Windows 맑은 고딕 또는 Linux NanumGothic을 사용하며 `MEMORIAL_PDF_FONT`로 임베드 가능한 TTF 경로를 지정할 수 있습니다. ZIP은 열람 가능한 기존 자료와 가족 앨범의 보관본, JSON을 담습니다(250MB 이하).
- 초대 링크: 새 초대는 기본 30일입니다. 만료는 최초 접속 기간이 아니라 링크의 전체 접속 유효기간입니다. 기존 계정은 자동 만료시키지 않으며 계약자가 재발급/해제할 수 있습니다.
- 관리자 승인 대기 목록은 운영 확인용이며, 가족 자료의 공개·AI 활용 동의는 가족 계약자가 결정합니다.
