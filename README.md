# 봉안함 원격 참배 · AI 추모 대화 — MVP (0단계 시연 프로토타입)

여수 지장대사 봉안당을 1차 대상으로 한 "비전스튜디오 프리미엄(가칭)" 시연용 프로토타입입니다.
계획서(`bongan-remote-memorial-plan.md`)의 유족용 6화면 + 관리자용 5화면을 노트북 한 대와 웹캠으로 돌립니다.

- 개발 기획: [docs/DEV_PLAN.md](docs/DEV_PLAN.md)
- 웹캠 선정: [docs/WEBCAM_GUIDE.md](docs/WEBCAM_GUIDE.md)

## 관리자 바로 접속

바탕화면의 **봉안당 관리자** 아이콘 또는 프로젝트 폴더의 **관리자.bat**을 실행하면 서버를 확인하고 관리자 콘솔을 엽니다. 관리자 키는 실행 시 로컬 설정에서 읽으며 바로가기 파일에는 저장하지 않습니다.

## 1분 실행

가장 쉬운 방법: 바탕화면의 **봉안당 접속** 아이콘(= 프로젝트 폴더의 `시작.bat` = `run.ps1`)을 두 번 누릅니다.
서버(8765)와 현장 프로그램(웹캠)이 **창 없이** 켜지고(이미 켜져 있으면 건너뜀) 브라우저에 **시작 화면**(`http://127.0.0.1:8765/`)이 열립니다. 끄려면 **봉안당 종료** 아이콘(= `종료.bat` = `stop.ps1`).
로그는 `data\server.log`, `data\edge.log`(UTF-8)에 쌓입니다: `Get-Content data\edge.log -Encoding UTF8 -Tail 30`.
아이콘을 다시 만들려면(다른 PC): `run.ps1`·`stop.ps1`을 대상으로 하는 바로가기를 만들고 아이콘 파일 `assetsongan.ico`, `assetsongan-stop.ico`를 지정합니다.
시작 화면에는 관리자 콘솔과 시연 계정(이미영·이준호…) 열기 버튼이 있습니다. 이 화면은 서버를 켠 컴퓨터에서 직접 열었을 때만 나오고, 외부·프록시·Vercel에서는 나오지 않습니다(`LAUNCHER=0`으로 끌 수 있음).

명령으로 하려면:

```powershell
pip install -r requirements.txt
python -m server.seed              # 시연 데이터 + 초대 링크 출력
.
un.ps1                          # 서버 + 현장 프로그램 실행 후 시작 화면 열기(이미 켜져 있으면 건너뜀)
```

또는 창 두 개에서:

```powershell
python -m uvicorn server.main:app --port 8765 --reload
python -m edge.agent               # 웹캠 캡처 → 사람 감지 → 칸별 사진 업로드
```

| 화면 | 주소 |
|---|---|
| 유족 웹앱 | `http://127.0.0.1:8765/?t=<초대 토큰>` — `python -m server.seed` 가 출력 |
| 관리자 콘솔 | `http://127.0.0.1:8765/admin?key=admin1234` |
| API 문서 | `http://127.0.0.1:8765/docs` |

휴대폰으로 보려면 같은 와이파이에서 `127.0.0.1`을 노트북 IP로 바꾸고 `--host 0.0.0.0`으로 실행합니다.
음성 인식·합성은 크롬·삼성 인터넷·엣지에서 동작합니다(브라우저 내장 기능, 비용 없음).

## 시연 순서 (계획서 3장 서비스 흐름)

1. **관리자 콘솔 → 칸 좌표 등록**: 웹캠 화면 위에 큰 영역을 드래그 → 단·열 입력 → '격자로 나누기' → 저장. 1초 안에 현장 프로그램이 새 칸을 반영합니다.
2. **관리자 콘솔 → 계약·가족**: 계약을 열어 초대 링크를 복사(카카오톡으로 보내는 링크).
3. **유족 앱 → 참배**: 내 칸 사진(10초 갱신). '실시간으로 보기'로 30초 영상. 카메라 앞에 사람이 지나가면 자동으로 사진 화면으로 전환됩니다.
4. **사진을 누르면 → 추모 공간**: 고인 사진·생몰일·방명록·다가오는 기일.
5. **관리자 콘솔 → AI 설정**: Anthropic API 키 입력 → '연결 테스트' → 저장. (없으면 Mock 대화로 시연)
6. **대화**: AI 고지 확인 → 시작. 마이크 버튼으로 말하거나 글로 입력. 재산·의료·법률 질문은 정해진 답으로, 위기 신호("따라가고 싶다")는 고인 역할을 멈추고 109를 안내하며 대화를 닫습니다. 끝나면 요약만 저장됩니다.
7. **제사**: 일정 목록, 진행 중 행사 '중계 보기', 공양·헌화·기도 신청(결제는 모의).
8. **설정**: 가족 초대 링크 발급, **목소리 등록(앱에서 녹음)**, 지난 대화 요약, '작별 절차'(대화 기능 닫기 + 자료 반환/삭제).

## 화면 디자인 · 종교 테마

유족 앱은 따뜻한 아이보리 바탕과 차분한 녹색을 중심으로 구성했습니다. 명조 제목, 넉넉한 여백, 얇은 구분선으로 고요한 추모 공간을 표현하며 주요 버튼은 56px 높이로 유지합니다. 전용 스타일은 `server/static/css/family.css`에 있으며 관리자·현장 중계 화면과 분리됩니다.

- **뼈대(2026-10-12 개편, `css/serene.css`·`css/console.css`)**: 밝은 반투명 머리말(화면 도구·이름 표식), 둥근 카드. 메뉴는 휴대폰 = 아래 떠 있는 막대, 넓은 화면(1024px~) = 왼쪽 세로 막대. 화면 이동이 방문 기록에 남아 '뒤로 가기'가 앱 안에서 동작합니다.
- **시연 시작 화면 `/demo`**: 홈페이지(머리말 '원격 참배 시연', 03 추모 구역)와 플랫폼(머리말 'MVP 시연 바로가기', MVP 시연 화면)의 바로가기가 여는 주소입니다. 서버를 켠 컴퓨터에서는 '○○ 님으로 바로 체험', 가족 계정 목록, 직원 바로가기, 10분 시연 순서를 보여 주고, 온라인에서는 저장된 가족 링크로 가거나 초대 링크 붙여 넣기 화면을 보여 줍니다.
- 참배 첫 화면: 짧은 장면 띠 → 봉안함 화면 + 오른쪽 '실시간으로 뵙기'와 바로 하기 6칸, 다가오는 추도식. 상세 안내는 펼쳐 읽을 수 있습니다.
- 관리자 콘솔: 메뉴 묶음(오늘 · 가족·고인 · 의례·현장 · 설정), 위쪽 제목 막대, 화면 안 관리자 키 입력(쿠키가 있으면 생략).
- 종교별 테마는 전통(녹색), 불교(흙빛), 천주교(회청색), 기독교(청록색)의 은은한 강조색으로 구분합니다. 설정 → **추모 공간 꾸미기**에서 테마를 선택해 미리 본 뒤 **테마 적용하기**로 저장합니다. 계약자는 가족 공통 테마를 저장하고, 다른 가족은 이 기기에만 적용합니다. 적용 후에는 배경·액자·추모 문양이 함께 바뀌며 새로고침해도 유지됩니다.
- 테마별 여백 문양과 서체: 전통은 창살·Noto Serif/Sans KR, 불교는 연꽃·고운바탕/고운돋움, 천주교는 성당 아치·나눔명조/나눔고딕, 기독교는 십자가와 잎사귀·고운돋움/Noto Sans KR을 사용합니다. 미리보기에도 동일하게 반영됩니다. 문양은 로컬 SVG이며, 웹폰트 연결이 불가능하면 기기의 기본 명조·고딕으로 표시합니다.
- **움직임은 몽환적 실사 Lottie 장면만 씁니다(2026-10-12, CSS 키프레임 연출은 모두 걷어냄).** 장면 파일은 `python scripts/make_dream_lottie.py`(원본 이미지 폴더 기본값 `../_assets/dream-2026-10-12`)로 다시 만들고, 재생은 `js/dream.js`, 자리·빛은 `css/dream.css` 가 맡습니다.
  - 첫 화면(테마별): 배경 사진이 아주 느리게 확대·이동(불교는 윤회당 노을 바다 → 별밤 도량으로 교차), 전경 꽃(불교 연꽃·천주교/기독교 백합·일반 국화)이 미세하게 흔들리고, 연기 사진으로 만든 안개가 흐르며 빛망울·빛 번짐·가장자리 어둠. 1.5초 밝아짐 + 24초 끊김 없는 반복. 연꽃은 불교 테마에만 나옵니다.
  - 참배 실시간 보기 위: 양쪽 촛불(사진) 빛 흔들림 + 가운데 향 연기(2초 + 12초 반복)와 잠깐의 ‘○○ 님을 뵙습니다’.
  - 인공지능 대화: 밤의 작은 성소 판 위 고인 사진 둘레에 후광·안개·빛망울, 말하기(금빛 물결)·듣기(파란 고리) 표시.
  - 생중계 반응: 합장·촛불·헌화·마음이 빛망울과 함께 떠오릅니다(현장 TV 화면도 같음).
  - 인공지능 생성 이미지가 든 장면에는 화면 구석에 ‘인공지능 생성 이미지’(불교는 ‘사진: 지장대사 윤회당 · 연꽃: 인공지능 생성 이미지’)를 표시합니다. 시연 고인 김옥순 님 사진은 인공지능 생성 가상 인물 초상이며 그림 안에 그렇게 새겨 두었습니다(예전 ‘사진 자리’ 그림은 서버 시작 때 이 초상으로 바뀌고, 실제로 올린 사진은 건드리지 않음).
  - 설정 → 화면 움직임: 앱에서 줄이면 정지 장면 한 장. 기기의 움직임 줄이기만 켜져 있으면 절반 속도로 느리게 반복하고 ‘움직임 멈추기’ 단추를 줍니다. Lottie를 못 불러오면 배경 사진(대체 그림)이나 빈 자리로 두고 내용은 막지 않습니다. 화면 밖·숨은 탭에서는 멈춥니다.
- 하단 메뉴의 현재 위치 표시, 키보드 초점, 팝업 닫기·Escape·초점 순환을 지원합니다.

## 음성을 더 자연스럽게 (봇 느낌 줄이기)

관리자 콘솔 → AI 설정 → **음성 세부 설정**에서 안정감·유사도·표현력·말 빠르기를 슬라이더로 바꾸고 **저장 전에 미리 듣기**로 비교할 수 있습니다. 효과가 큰 순서:

1. **녹음 원본이 90%** — 또박또박 읽은 목소리는 봇처럼 나옵니다. 조용한 방에서 평소 대화하듯 웃고 쉬어 가며 **3분 이상**(여러 파일 총 5분 안팎) 녹음해 다시 등록하세요.
2. 슬라이더 — 안정감 0.35~0.45, 표현력 0.3~0.45, 속도 0.9~0.95(어르신 말투). 기본값이 이 범위입니다.
3. 모델 — `eleven_v3`가 감정·억양이 가장 자연스럽지만 답이 2~4초 늦습니다(안정감은 0/0.5/1 세 단계로만 적용, 속도 미적용). 실시간이 필요하면 `eleven_v3_conversational`.
4. **Professional Voice Clone** — Creator 요금제(월 $11~)부터, 깨끗한 음성 30분 이상(3시간 최적)이면 원본과 거의 구분되지 않습니다.
5. 다른 API(2026-09-19 조사) — **Fish Audio S2.1 Pro**(한·중·일에 강함, TTS-Arena 상위, 짧은 샘플 복제, 저렴), **Cartesia Sonic 3.6**(한국어, 40~90ms 초저지연 → 실시간 아바타용), **MiniMax Speech-02**(다국어·저비용). 국내 **Supertone**은 검색 결과에 "2026-08-31 API 종료" 공지가 보였으나 문서 페이지가 열리지 않아 직접 확인하지 못했습니다. 어느 것이든 `server/ai/tts.py`에 공급자 클래스 하나를 더하면 붙습니다. 결정은 같은 문장으로 비교 청취한 뒤 하기를 권합니다.

### ElevenLabs API 키 설정 (편집창 항목별 선택값)

키를 만들 때 **키 제한 토글을 끄면** 아래 표는 볼 필요가 없습니다. 제한을 켠다면 그대로 따릅니다. 켜는 건 **텍스트 음성 변환=접근, 음성=작성, 사용자=접근** 세 개뿐이고 나머지는 전부 접근 불가입니다.

| 구분 | 항목 | 선택 |
|---|---|---|

키는 **생성 직후 한 번만 보이는 `sk_…` 전체 값**을 복사해 관리자 콘솔 → AI 설정 → ElevenLabs 키에 저장합니다. 키 목록의 짧은 요약본은 쓸 수 없고, 옛 키를 지우면 콘솔의 키도 새 것으로 바꿔야 합니다. 같은 표가 관리자 콘솔 AI 설정 화면 안에도 접혀 있습니다.

### Railway에 올리기 (2026-10-12)

상시 실행 서버 + 볼륨이라 실시간 참배·기록 저장·알림톡 예약까지 그대로 동작합니다. 설정 파일: `.railway/railway.ts`(아래 '인프라 설정 파일' — 시작 명령·상태 확인 `/health`·재시작·인스턴스 1개·볼륨), `railpack.json`(빌드 단계 시작 명령), `.python-version`(3.12), `.railwayignore`(`.env`·`data/`·`edge/` 는 올리지 않음).

1. 프로젝트·서비스·볼륨: `railway init --name <이름>` → `railway add --service memorial` → `railway service link memorial` → `railway volume add --mount-path /data`
2. 일반 변수: `DATA_DIR=/data`, `LAUNCHER=0`, `AUTO_SEED=1`(처음에 시연 데이터를 넣을 때만), `KAKAO_SEND_ENABLED=0`
3. 비밀 키: **`powershell -NoProfile -File scripts\railway-keys.ps1`** — 강한 무작위 `ADMIN_KEY`·`EDGE_KEY`·`SEED_SALT` 를 만들어 넣고, 관리자 키는 내 문서 폴더에만 저장합니다. Railway 에서는 키가 기본값이거나 24자보다 짧으면 서버가 켜지지 않습니다(`server/config.py`).
4. 배포·주소: `railway up --service memorial --detach` → `railway domain --service memorial`
5. 인공지능·음성 키(`ANTHROPIC_API_KEY` 등)는 Railway 화면의 Variables 에서 직접 넣습니다. 넣지 않으면 시연용 응답(Mock)으로 동작합니다.
6. 현장 카메라 프로그램(`edge/`)은 봉안당 PC 에서 돌리고 `SERVER_URL` 을 Railway 주소로, `EDGE_KEY` 를 위 키로 맞춥니다.

SQLite 한 파일을 쓰므로 인스턴스는 1개로 둡니다(여러 개로 늘리면 기록이 갈라집니다).

#### 인프라 설정 파일: `.railway/railway.ts` (2026-10-12, `railway.json` 대체)

`railway.json`(Config as Code)은 2026-12-01 까지만 지원되어 `.railway/railway.ts`(Infrastructure as Code)로 옮겼습니다. `railway config pull` 로 지금 Railway 의 볼륨(`memorial-volume` → `/data`)·변수(값은 `preserve()` 로 Railway 에만 둠)를 가져오고, 빌드(Railpack)·시작 명령·상태 확인(`/health`, 120초)·재시작(실패 시 5회)·인스턴스 1개를 옮겼습니다. SDK(`railway` npm 패키지, Railway 공식)는 `.railway/` 안에만 설치합니다(앱 빌드가 Node 로 바뀌지 않게, `.railwayignore` 로 업로드 제외).

```powershell
cd .railway; npm install; cd ..          # 처음 한 번
# 윈도우에서는 SDK 가 CLI 버전을 확인할 때 실제 railway.exe 경로가 필요합니다(npm 으로 설치한 CLI 는 .cmd 껍데기라서).
$env:_ = "$env:APPDATA\npm\node_modules\@railway\cli\bin\railway.exe"
& $env:_ config plan      # 바뀔 내용만 보여 줌. 'destroy' 가 0 이 아니면 적용하지 마세요(볼륨 삭제 = 기록 삭제).
& $env:_ config apply     # 확인 후 적용
```

2026-10-12 에 적용을 마쳤고(`config plan` → "already up to date") `railway.json` 은 지웠습니다. 재시작 방식은 Railway 기본값(실패 시 재시작)이라 파일에 적지 않습니다(적으면 Railway 가 기본값을 비워 저장해 늘 '변경 있음'으로 보입니다). `railpack.json` 은 Railpack 빌드 설정이라 그대로 둡니다.

Vercel에 올릴 때 환경변수: `AUTO_SEED=1`(시작 시 시연 데이터), `SEED_SALT=아무문자열`(초대 링크 고정), `ADMIN_KEY`, `EDGE_KEY`. API 키는 배포 뒤 관리자 콘솔에서 넣되, 서버리스는 재시작 시 사라지므로 `ANTHROPIC_API_KEY`·`ELEVENLABS_API_KEY`를 환경변수로 넣는 편이 낫습니다. 진입점은 `pyproject.toml`의 `[tool.vercel] entrypoint`.

## 제사 생중계 (틱톡 라이브식 쌍방향)

| 구분 | 공개 범위 | 화면 |
|---|---|---|
| 법회·행사 (`open`) | 계약 가족 누구나 | 전체 화면 생중계 + 가족 메시지·반응 |

## 웹캠 없이 시연하기 — 시연 카메라 (2026-10-12)

현장 프로그램(`edge.agent`)과 웹캠이 없어도 **원격 참배·실시간 보기·제사 생중계**가 그대로 동작합니다. 서버가 켜질 때 `server/demo_camera.py` 가 함께 돌며, 실제 카메라 신호가 없는 카메라에 대해 윤회당 봉안실 사진(안치실 카메라)과 법당 사진(제례 카메라)으로 화면을 만듭니다(`server/static/images/demo-camera/`, 윤회당 사용 허락 사진).

- 사진은 아주 느리게 확대·이동하고 촛불처럼 밝기가 흔들려 실시간처럼 보이지만, 화면 왼쪽 위에 **‘시연 화면 · 시각’**이 새겨지고 유족 앱 상태줄·관리자 현황에도 **시연 화면**으로 표시됩니다. 실제 현장 중계로 보이게 쓰지 않습니다.
- 관리자 콘솔 → 현황 → **시연 카메라**: `자동`(기본, 웹캠이 없을 때만) · `항상 시연 화면` · `끔`. 환경변수 `DEMO_CAMERA` 로 기본값을 정할 수도 있습니다(콘솔 설정이 우선).
- 시연 카메라가 도는 카메라의 의례 일정은 날짜와 상관없이 생중계 창이 열립니다(시연 모드와 같은 규칙).
- 실제 웹캠(현장 프로그램)이 연결되면 `자동` 에서는 웹캠 화면이 우선하고 시연 카메라는 그 카메라를 건드리지 않습니다.
- Railway 처럼 한글 글꼴이 없는 서버에서는 화면에 `DEMO 시각`으로 새기고, 한글 ‘시연 화면’ 표시는 유족 앱이 맡습니다.

바로가기 주소: 유족 앱은 `/?t=<초대 토큰>#ritual` 처럼, 관리자 콘솔은 `/admin?key=<키>#aisettings` 처럼 탭을 지정해 열 수 있습니다(토큰·키만 주소에서 지우고 탭 지정은 남깁니다).

## 실시간 보기가 끊기거나 느릴 때

- **노트북 시연에서 몇 초마다 멈춤 · 화면이 흐림**: 관리자 콘솔 → 현황 → **시연 모드** 카드에서 "시연 모드로 (둘 다 끔)". 참배객 감지(사람이 잡히면 송출 중단)와 옆 칸 가리기(내 칸만 잘라내고 바깥은 흐림)가 꺼져, 카메라 화면 전체가 끊기지 않고 선명하게 나옵니다(내 칸은 테두리만). 웹캠에서 작은 칸만 잘라 키우면 흐려 보이기 때문입니다. 유족 앱 상태줄에 "시연 모드"가 표시됩니다. 안치실에 설치하면 "운용 모드로 (둘 다 켬)". 현장 프로그램은 1초마다 설정을 읽어 재시작 없이 반영됩니다.
- 실시간 보기·라이브 화면에서는 영상을 흐리는 효과를 쓰지 않습니다(등장 연출은 밝아지기만, 실시간 아바타 위 안개는 제거, 라이브 배경은 단색).
- 현장 프로그램은 720p로 찍어 칸 바깥을 1/4 크기에서 흐린 뒤 보내고(1080p 큰 반경 흐림보다 약 10배 빠름), 서버 전송은 별도 스레드라 보내는 동안 캡처가 멈추지 않습니다. 전송이 밀리면 오래된 프레임을 버리고 최신 화면을 보냅니다. 초당 프레임은 `.env`의 `LIVE_FPS`(기본 12).
- 그래도 느리면 `.env`의 `CAPTURE_WIDTH/HEIGHT`를 낮추거나 `LIVE_FPS`를 8로 내립니다.

## 현장 프로그램이 죽었을 때

관리자 콘솔 현황에서 카메라가 "끊김"이면 현장 프로그램이 꺼진 것입니다(유족 앱의 실시간 보기가 "카메라 연결 안 됨"으로 나옴). 프로젝트 폴더에서 다시 실행하세요:

```powershell
python -m edge.agent
```

`run.ps1`(= `시작.bat` = 바탕화면 **봉안당 접속**)은 서버와 현장 프로그램 중 꺼진 것만 골라 창 없이 띄운 뒤 시작 화면을 엽니다. 현장 프로그램은 서버가 잠시 내려가도(자동 재시작 등) 스스로 재접속합니다.

## 설계에서 지킨 것 (계획서 4·5·7장)

- **원본 영상은 서버·휴대폰에 가지 않습니다.** 현장 프로그램이 내 칸만 잘라내고 바깥을 흐린 뒤 보냅니다. 관리자 좌표 등록용 전체 화면만 예외이며 열람은 기록됩니다.
- **사람이 보이면 송출을 멈춥니다.** 사진 갱신·실시간 영상 모두 중단되고 유족 화면은 마지막 사진으로 바뀝니다. 영상은 저장하지 않습니다.
- **현장에서 밖으로 나가는 연결만** 씁니다. 서버가 카메라로 들어가는 길이 없습니다.
- **AI 표시 상시 노출**, 아바타는 아무것도 팔지 않음(응답에서 권유 문장 제거), 15분 제한, 요약만 저장, 동의서 없으면 대화 불가, 미성년자 보호자 확인, 작별 절차.
- LLM·TTS는 인터페이스로 분리되어 공급자 교체가 가능합니다(`server/ai/base.py`).
